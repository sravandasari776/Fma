## Design bugs found and fixed

Before this work the original 925-vector regression passed 909/925 and the unit tests did not catch these (each block was correct on its own). Each bug now has its own regression vector:

| # | Bug | Fixed in | Regression vector | Now |
|---|---|---|---|---|
| B1 | SP products cut to 24 bits: guard bit lost, 1 ULP low | `stage1_exp_align_controller.v, fma_top.v, fma_lane_pipe.v` | `DIR_BUG1_SP_product_guard` | **PASS** |
| B2 | Subnormal results truncated instead of rounded (double rounding) | `stage4_normalization.v, stage4_output_finalize.v` | `DIR_BUG2_E5M2_subnormal_round` | **PASS** |
| B3 | Sign of a lost (sticky) remainder wrong for negated terms: 1 ULP high | `align_shifter.v, stage2_invert_swap.v` | `DIR_BUG3_sticky_sign` | **PASS** |
| B4 | Accumulator overflow: 1.75 + 4 x 1.75 gave -7.25 instead of 8.75 | `fma_defs.vh (76-bit frame, 3 headroom bits)` | `DIR_BUG4_headroom_pos` | **PASS** |
| B5 | Exact FMA cancellation broken: -(1+2^-22) + (1+2^-23)^2 gave 2^-36, not 2^-46 | `stage1_exp_align_controller.v (exact 48-bit product)` | `DIR_BUG5_SP_exact_cancel` | **PASS** |
| B6 | -Inf addend produced +Inf | `fma_lane_pipe.v, stage4_sign_detection.v` | `DIR_BUG6_neg_inf` | **PASS** |
| B7 | Inf + (-Inf) produced Inf instead of NaN | `fma_lane_pipe.v` | `DIR_BUG7_inf_minus_inf` | **PASS** |
| B8 | -0 + (-0)*x produced +0 instead of -0 | `fma_lane_pipe.v, stage4_sign_detection.v` | `DIR_BUG8_neg_zero` | **PASS** |
